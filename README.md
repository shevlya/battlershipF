## Особенности интерфейса
Приложение разработано с упором на визуальную согласованность и удобство пользователя:
- **Единый стиль кнопок**: пастельно-фиолетовый цвет, белый текст по центру, одинаковый размер для всех элементов управления.
- **Визуальное восприятие**: использование градиентов и фоновых изображений с мягким затемнением для улучшения читаемости контента.
- **Масштабируемость**: увеличенный и адаптивный интерфейс игрового поля для комфортной игры.
- **Стилизация**: активное использование SCSS-синтаксиса для модульной и поддерживаемой стилизации компонентов Angular.

## Требования
Перед началом работы убедитесь, что у вас установлены:
- **Node.js**: `v20.9.0` или выше
- **npm**: `v10.1.0` или выше

Проверить версии можно командами:   
```bash
node -v
npm -v
ng version
``` 

## Установка и настройка
1. Клонирование и установка зависимостей
```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd <ИМЯ_ПАПКИ_ПРОЕКТА>
npm install
``` 
2. Настройка окружения
Приложение требует указания адреса backend-сервера.
Если вы запускаете проект впервые:    
```bash
# Скопируйте шаблон в рабочий файл
cp src/environments/environment.example.ts src/environments/environment.ts
```
Настройка файла `src/environments/environment.ts`    
Откройте файл и укажите актуальный IP-адрес вашего backend-сервера:    
  ```typescript
  export const environment = {
    production: false,
    apiUrl: 'http://ВАШ_IP_АДРЕС:8080' // Замените на реальный IP (например, 192.168.1.15)
  };
  ```
Для пользователей, обновляющих проект:   
Если файл `environment.ts` уже существует и добавлен в `.gitignore`, он не будет перезаписан при `git pull`. Однако рекомендуется проверить, что `apiUrl` в нём актуален для вашей текущей сети.

## Запуск приложения

### Локальная разработка
Запустите сервер разработки:    
   ```bash
   ng serve
   ```
Приложение будет доступно по адресу: `http://localhost:4201/`

### Игра по локальной сети (с другим человеком)
1. Откройте файл `src/app/services/auth.service.ts` и убедитесь, что там указан ваш локальный IP-адрес (например, 192.168.x.x), а не localhost.
2. Запустите приложение с привязкой ко всем сетевым интерфейсам:
```bash
ng serve --host 0.0.0.0 --port 4201
```
3. Сообщите свой локальный IP-адрес второму игроку. Он сможет открыть игру в браузере по адресу:
`http://<ВАШ_IP_АДРЕС>:4201/`
